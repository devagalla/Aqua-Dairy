# Aqua-Dairy

## Run locally

1. Copy `.env.local.example` to `.env.local` and enter your Supabase project URL and public anon key. Add a Google Maps browser API key restricted by HTTP referrer for the Maps JavaScript API and Places API if you want locality suggestions.
2. Apply every SQL migration in `supabase/migrations` to your Supabase project in filename order (`supabase db push` from a linked project, or run each file in the Supabase SQL editor). If earlier migrations are already applied, run any newer migration files that have not been applied yet. Migrations `202610170005_repair_growth_samples_schema.sql` and `202610170006_repair_farm_workflow_tables.sql` repair workflow database objects and refresh Supabase's API schema cache. Migration `202610170007_add_multi_farm_pond_setup.sql` enables adding multiple named farms and creating a pond together with its first culture cycle. Migration `202610170008_add_pond_weather_locations.sql` adds saved pond locations for local weather forecasts. Migration `202610170009_model_feed_entries_and_cycle_status.sql` adds one-feeding and daily-summary feed records, marks older cycles completed except each pond's most recent cycle, and enables explicit cycle completion. Migration `202610170010_repair_alert_log_columns.sql` ensures alert message/action fields exist and reloads the API schema cache. Migration `202610170011_add_farm_income_tracking.sql` adds income/expense transaction types and a farm finance summary RPC. Migration `202610170012_allow_alert_acknowledgement.sql` enables safe alert acknowledgements, and `202610170013_water_log_alert_idempotency.sql` makes water-log sync retries idempotent; apply both to enable these updates.
3. In Supabase Authentication → URL Configuration, set the Site URL to `https://www.aquadairy.xyz` and allow the callback URLs listed in `.env.local.example` (also allow `https://aqua-dairy.vercel.app/auth/callback` and `http://localhost:3000/auth/callback`).
4. To enable bot protection, create a Cloudflare Turnstile widget with `aquadairy.xyz`, `www.aquadairy.xyz`, `aqua-dairy.vercel.app`, and `localhost` in its allowed hostnames. Set its site key as `NEXT_PUBLIC_TURNSTILE_SITE_KEY` locally and in Vercel. In Supabase, open Authentication → Bot and Abuse Protection, enable CAPTCHA, select Cloudflare Turnstile, and enter the widget secret key. Never add the secret key to `.env.local` or client-side code. Signup, password sign-in, and signup-verification resend require a completed CAPTCHA token when this is configured.
5. Run `npm install`, then `npm run dev`.

Use `npm test` to run the unit tests and `npm run build` to verify a production build.

## Shrimp photo screening and pond weather

The protected Shrimp health page runs the trained ONNX image classifier in the visitor's browser. The model file and four-class labels are in `public/models/`; photos are not uploaded or saved. The result is an initial visual screening only, not a diagnosis. Weather cards use Open-Meteo's forecast API for a seven-day outlook and its archive API for hourly weather from seven days ago. Both require saved pond coordinates.

Water, feed, growth, and expense entries can be saved to this browser's IndexedDB while offline and sync automatically after connectivity returns. Pending and failed entries remain visible in their journal, with a manual retry for failures. Farm and active-cycle selectors are cached per signed-in account. Offline records remain on the device until synced or explicitly deleted; this implementation does not cache private pages or upload photos. Keep an already-open logging page available while disconnected; authentication and a fresh page load still require connectivity.
